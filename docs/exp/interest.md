# `¥` / `$` —— 利息变量：读一次，长一点

`¥`（U+00A5，也接受全角 `￥`）和 `$` 是**变量声明的利息前缀**，核心语义一句话：

> **变量只在被读取时才结算利息：先返回当前值，再结算；同一表达式里读几次，就结算几次。**

- `¥[利率] x = 初值` —— **单利**：每次读取固定增加 `本金 × 利率`。本金 = 这一条规则**诞生那一刻** `x` 的值，之后永远不变（像贷款：利息按当初的本金算）。
- `$[利率] x = 初值` —— **复利**：每次读取把 `x` 变成 `x + x × 利率`（利息也生息）。
- `¥x = 初值`（不带 `[利率]`）→ 默认利率 **0.0001**。

## 单利：读得越多，涨得越多

```
¥[0.1] a = 10        // 本金 10，单利 10% → 每次读取固定 +1
print(a)             // 10（先返回 10，再让 a = 11）
print(a)             // 11（先返回 11，再让 a = 12）
print(a)             // 12
print(a + a + a)     // 10 + 11 + 12 = 33 —— 表达式里的三次读取，各自结算一次
print(a)             // 13
```

## 复利：利滚利

```
$[0.1] b = 10
print(b)             // 10（返回后 b = 11）
print(b)             // 11（返回后 b = 12.1）
print(b)             // 12.1
```

## 同名规则按定义顺序叠加

每写一条 `¥`/`$` 声明，就给这个变量**追加**一条规则；每次读取按**声明顺序**把它们全部结算一遍：

```
¥[0.1] x = 10        // 规则 1：单利 +1（本金 10）
¥[0.1] x = 10        // 规则 2：单利 +1（本金仍是 10）
$[0.1] x = 10        // 规则 3：复利 10%（按当前值算）
print(x)             // 10  → 10 +1 +1 +10% = 13.2
print(x)             // 13.2
```

## 变量类型与初值

- 利息变量是**浮点**。整数初值自动转成浮点：`¥[0.1] n = 10` → `10.0`。
- 之后的普通赋值也自动转浮点：`n = 20` 等价于存 `20.0`，**不改变**已挂上的规则，后续读取继续按原规则结算。
- 字符串/数组等复合类型初值 → 编译错误。
- 如果同一个名字**已经以非浮点类型存在**（例如 `int x`），再用 `¥`/`$` 声明 → 编译错误 `already exists as a non-float variable`；反过来，`¥`/`$` 声明过的名字可以安全地被普通赋值复用（对象始终是同一个浮点存储）。

## 默认利率

```
¥c = 100
print(c)             // 100
print(c)             // 100.010002 （0.0001 × 100 = +0.01，float 精度打印如上）
```

## 实现方式

- 纯 **LLVM 后端**实现。`¥`/`$` 在**每个函数体内**维护一张"变量 → 规则表"（`interestVars`）：单利规则在声明时把 `本金 × 利率` 预计算成一条常量（IR 里的 `fmul` 结果），复利规则只记利率。
- 每次读取 `x` 展开成一段**直线指令**：`load x → 把值交给表达式 → 按定义顺序把每条规则结算一遍 → store 回 x`。因此同一条语句里的多次读取看到的是**依次变大的值**（先读先涨）。
- 规则表按函数隔离（`codegen(Function)` 与按钮处理函数里保存/清理/恢复），不会跨函数泄漏。
- 与 `disposable` 的差异：`¥`/`$` 是**声明**（变量名会记录、可被后续普通赋值复用），`disposable` 不是声明。

## 编译错误一览

| 场景 | 错误信息关键词 |
|---|---|
| `¥[abc] x = 1`（利率不是数字） | `Expected an interest rate number in '[' ... ']'` |
| `¥[0.1] x` 少了 `]` | `Expected ']' after the interest rate` |
| `¥[0.1] = 5`（漏变量名） | `Expected variable name after the interest prefix ('¥' or '$')` |
| `¥[0.1] x 5`（漏 `=`） | `Expected '=' after the interest variable name` |
| 同名变量已是 int/long/bool/字符串等 | `already exists as a non-float variable` / `cannot be an interest variable` |

## 与其它 EXP 的关系

- 与 `disposable`（一次性）互补：`disposable` 让可用次数"有限"，`¥/$` 让每次读取都会"增值"。
- 与 `fate`（命运回拉）、`deja`（偷未来）、`wrath`（改写历史）无关：`¥/$` 不改时间线，只让"读取"这件事产生副作用。若既被 `fate` 声明又被挂利息规则，`fate` 在赋值存储时回拉、`interest` 在读取返回前结算，两者按各自时机独立生效。
