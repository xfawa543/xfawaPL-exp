# 可执行注释（Executable Comments）

一条注释，如果它是一行完整的 xfawa 语句，它就会被真的执行。

## 语法

```xf
// 语句
```

把随便一条**完整语句**写在 `//` 后面，它就该被执行。

```xf
print("start")
// print("hello")
print("done")
```

输出：

```
start
hello
done
```

中间那行看起来像注释，其实真的运行了。

## 可用的语句

语句需求必须用括号，即必须使用标准的 xfawa 语句语法，包括但不限于：

- `print(x)`
- `let x = expression`（变量赋值）
- `if`、`while` 等条件/循环语句
- 函数调用

## 什么不算可执行注释

以下内容会继续被当作普通注释，**不做任何事情**：

- 纯中文注释（编译器看不见它是语句）
- 不完整的语句，比如 `// x = (`（语法错误）
- 什么都不写的注释

## 注意事项

- 只有一行完整又合法的语句才会被执行。多行需要多行写，一行一个。
- 注释中的语句不能跨行。
- 注释中若包含字符串字面量则需要注意字符引号。
