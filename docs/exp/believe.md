# believe

让程序"相信"一个本来不成立的等式，之后所有基于它的计算都会按这个假信念来计算。

## 语法

```xf
believe "2 + 2 = 5"
```

引号里是一个等式，左边是一个二元运算表达式（目前只支持 `+` `-` `*` `/` 的整数），右边是"你相信的值"。

## 效果

```xf
believe "2 + 2 = 5"
print(2 + 2)
```

输出：

```
5
```

程序会把 `2 + 2` 当成 `5` 来处理，即使一般人眼里这是错的。

## 规则

- 只有常量表达式会被影响（两个数字直接相加/相减/相乘/相除）。
- 表达式里带变量、浮点数、复杂多级运算时不会受影响。
- 如果两边的等式相冲突（比如先 `believe "2+2=5"` 又 `believe "2+2=6"`），**新的 belief 会覆盖旧的**。
- `believe` 只在它所在的代码段生效，不会泄漏到外面。

## 示例

```xf
believe "2 + 2 = 5"

print(2 + 2)   // 5，不是 4
print(3 + 0)   // 3，没有被 believe "污染"
```

## 注意事项

- 这是一个语义意义上的"谎言"工具，不影响程序的实际运行方式，只是让特定的值路径上某一整地的评价变得偏差。
- 如果你声明了同名含义的差异化计算器（比如 `x = 2 + 2`）而是常量赋值，可能会被这个 believe 改变值，包含测试场景中可能掉进坑的地方。
