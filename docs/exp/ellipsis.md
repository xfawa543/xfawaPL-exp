# ...（随机真实调用一个安全函数）

写一个单独的三个点 `...`，让程序在运行时**真正调用**一个随机选中的安全函数，并按照该函数参数的真实类型生成随机参数传进去。不再只是打印文本，而是真的执行。

## 语法

```xf
...
```

注意：这是单独一行、只有三个点的语法，不能带参数。数组范围 `[1...100]` 是不同的语法，互不影响。

## 效果

每次执行 `...`：

1. 在**当前程序里被定义的所有用户函数**加一个**预先挑选好的安全内置函数集合**中，随机挑一个；
2. 按它真实签名里的参数类型生成随机值：
   - `bool` → 随机 true/false；
   - `int` → 随机整数；
   - `long` → 随机大整数；
   - `float` → 随机浮点数；
   - `string` → 随机可打印字符串（自动以 `\0` 结尾，安全）；
   - 无参函数直接调用；
3. 真正执行该函数，输出会反映它的真实效果。

内置候选只包括真正无害的：`rand()`、`clock()`、`time(NULL)`。其他一概不选。

## 安全性（绝不调用）

- `main` 永远不会被随机调用；
- 函数体里含 `input()`（会阻塞等待输入）、`boom`、`bsod` 的函数会被排除；
- 参数含数组类型、无法安全生成参数的函数会被排除；
- 危险/系统/文件/窗口 API 不在候选里。

## 递归保护

允许用户函数里再写 `...`（递归/互相引用），但有一个全局最大调用深度（32）：
超过深度后直接放弃调用并返回，程序永远不会因为随机调用而爆栈或死循环。

## 示例

```xf
#test {
    fn main() {
        print("start")
        ...
        print("end")
    }

    fn sayHi() {
        print("HI!")
    }

    fn combine(a, b) {
        print(a + b)
    }
}
```

可能的输出之一（sayHi 被选中时）：

```
start
HI!
end
```

另一种可能（combine 被选中，参数是随机的两个整数）：

```
start
-1975741
end
```

随机选中了内置函数（rand/clock/time）时会正常运行但没有任何可见输出。

## 实现说明

- 编译期收集候选（用户函数过滤安全后 + 安全内置），`...` 处生成 `rand() % N → 全局函数指针表 → trampoline → 真实调用` 的运行时分发；
- 每个候选的 trampoline 里按 LLVM 真实签名生成参数（`__xfa_dots_str_N` 全局缓冲区放随机字符串）；
- 选择逻辑复用 `rand()`，首个 `...` 执行时自动播种。
