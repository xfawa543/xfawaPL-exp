# a <->[K] b（可逆反应）

把两个变量之间的差额往平衡的方向拨：左边多出来的会往右边走，右边多出来的会往左边走，一步走完差额/K。反应不创造也不销毁——`a + b` 永远不变。

## 语法

```xf
a <->[K] b
```

`K` 是非负整数（写在 `[ ]` 里）。

## 效果

```xf
int a = 10
int b = 90

a <->[1] b
print(a)              # 30：差 40 的一半
print(b)              # 70：正好挪过去 20
print(a + b)          # 100：总和守恒
```

一步反应把当前的差额 `|a - b|` 除以 K，从"多"的一边拨到"少"的一边：

- 目标是 `a` 拿 `T/(1+K)`、`b` 拿 `T·K/(1+K)`（`T = a + b`），向上取整的余数留在 `b`。
- `K = 1` 时一步走一半差额；`K = 2` 时走五分之一（差额/K 后再分给两边）。
- 两边已经很接近（差额 ≤ 1）时，改成随机游走：以接近平衡的方式随机分配。

`a + b` 在反应前后永远不变（整数除法的余数按规则留在一边，总和仍守恒）。

## 规则

- 反应是**可逆**的：再反应一次，会继续往平衡的方向走（或随机游走）。
- 两边一样（差额 0）时，反应什么都不发生。
- 反应的步长由 `K` 控制：`K` 越大，一步走得越少。

```xf
int m = 0
int n = 100

m <->[2] n
print(m)              # 16：差 33 的五分之一
print(n)              # 84
print(m + n)          # 100
```

## 注意事项

- 目前只支持 **int / long** 类型的变量。float 或其它类型不能参与反应（编译报错）。
- `a` 和 `b` 必须是两个**不同的**已声明变量（同一个变量和自己反应 → 编译报错）。
- 平衡点可能落在分数上（如 100/3），整数运算会把余数留在一边。
