# zombie —— 算术瘟疫

`zombie <变量>` 让一个数值变量**感染**瘟疫。从此它参与的**算术运算**不再按数学算，
而是"取最左边那个带瘟疫的值"当作结果，并且**永久传染**给运算里出现的所有变量。

一句话：这门语言会生病；生病的数字和干净的数字做加法，得到的还是那个病人的数字。

```
fn main() {
    a = 1
    b = 2
    zombie a
    c = a + b   // 结果取最左的瘟疫值 a = 1
    print(c)    // 1
    print(b)    // 2：b 只是"接触"了一下，仍然健康
    print(a)    // 1：a 永远是 1
}
```

## 语法

```
zombie <变量>
```

只对 `int` / `long` / `float` 有效；同一个变量重复 `zombie` 无副作用。

## 规则

1. **触发条件**：一个表达式里**至少有一个**已感染变量，并且该表达式是**算术运算**
   （`+ - * / %` 和一元 `-`）。比较（`== != < > <= >=`）和逻辑（`&& || !`）不算。
2. **取值**：从左往右找**第一个**已感染的变量，结果就等于它**当前**的值——
   不看运算符，也不看右边是什么类型。
3. **传染**：表达式里出现的**每一个**变量，运算之后都变成感染者（永久）。
   结果变量如果是赋值目标，也变成感染者。
4. **永久**：`zombie` 没有治愈。一旦感染，该变量在这个函数里永远带病。
5. **复制传染**：`c = a`（a 已感染）→ c 立刻感染；`c = a + b` → c 感染。
6. **不跨函数**：瘟疫是每个函数自己的状态。函数参数收到的是**普通值**，
   函数体内看不到调用者的感染情况（和 `disposable` / `interest` 的隔离规则一致）。
7. **列表是洁癖**：把感染值放进列表 / 数组元素是编译错误——瘟疫没法藏在容器里。

```
fn main() {
    a = 10
    b = 3
    zombie a
    c = a + b   // 10：a 是最左的感染者
    print(c)    // 10
    print(b)    // 3：b 被传染了，但这次运算的"病人"是 a
    d = b - a   // 现在 b 也感染了：最左的病人是 b 自己
    print(d)    // 3：b - a 恒等于 b
    e = a * a
    print(e)    // 10：a * a 恒等于 a
}
```

## 类型

| 病人类型 | 例子 |
|---|---|
| `int` | `a = 10, zombie a, b = 3, c = a + b` → `c = 10` |
| `long` | 同整数语义（64 位） |
| `float` | `a = 1.0, zombie a, b = 2.5, c = a + b` → `c = 1.000000` |

## 编译期错误

| 写法 / 场景 | 报错 |
|---|---|
| `zombie nothing`（不存在） | zombie: 变量 'nothing' 不存在（只能标记已声明的数值变量） |
| `zombie arr`（列表） | zombie: 'arr' 是列表，瘟疫无法在列表里传播 |
| `zombie s`（字符串 / 其它非数值） | zombie: 's' 不是数值变量（只有 int/long/float 能被感染） |
| `arr = [b]`，b 已感染 | [zombie] 变量 'b' 已感染，瘟疫无法藏进列表 |

## 边界 / 有意为之

- 感染是**编译期**静态判定的：`zombie` 写在循环里也照样感染本函数中它之后的所有使用点。
- 字符串拼接、数组下标等操作不触发也不传染（只支持第 2 条列出的算术运算）。
- 一次 `valuable` 代码运行有独立作用域，瘟疫**不会**从使用点传进去，也不会从里面传出来。
- 实现位置：`src/llvm/xfawa_llvm_codegen.cpp`（`codegen(ZombieStatement)`、
  `zombieAnnihilates()`，赋值传染在 `codegen(AssignmentStatement)`，容器检查在
  `codegen(ArrayLiteral)`）；词法/语法/AST 见 `src/lexer/lexer.cpp`、`src/parser/parser.cpp`、
  `src/include/xfawa_ast.h`；测试见 `tests/exp/test_zombie_*.xf`
  （`pwsh -File tests/run_zombie_tests.ps1`）。
