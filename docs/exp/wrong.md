# wrong —— 反事实守卫

`wrong <条件>` 给程序装一个 **反事实守卫**：当条件在运行时为"真"时，守卫立刻把参与者**最小扰动**到让条件变"假"，然后带着新结果继续执行。

一句话：程序亲眼看见了一个"不该出现的结果"，于是当场随机拨动 1 到 5，让这个结果消失。

```
fn main() {
    x = 10
    wrong x == 10
    print(x)      // 11..15：把 x 随机加 1..5（这次可能是 15），条件变为假
}
```

## 语法

```
wrong <布尔表达式>
```

`<布尔表达式>` 只能由数值运算与比较构成；不能含函数调用、数组元素或字符串。

## 扰动规则

1. **找参与者**：条件里所有变量，扩张出派生链（`z = x + y` 里 `z` 的最终生产者）；
   来源是 `x = <常数>` 之类"读不到其它变量"的叶子，才是能被直接扰动的**根**。
   `z = x + y` 的情形里，根是 `x` 与 `y`；`z` 每次扰动后沿 `x + y` 重算，保持关系一致。
2. **试推顺序**（按根在源码中的顺序）：整数的上拨是 **1..5 随机挑选**（运行时
   `rand()%5+1`，每次触发重新随机），失败后按 `-1, +2, -2, +3, -3, +4, -4` 逐探；
   浮点按 `max(|v|·1%, 0.01)` 的步长；布尔直接翻转。
3. **关系边界**：顶层关系 `x < E / x > E / x <= E / x >= E`（`x` 为整个操作数）直接跳到
   边界 `E / E / E+1 / E-1`，比逐格试探更省一步。
4. **派生重算**：扰动根之后，派生变量沿"最后一次赋值的右侧表达式"重算。
5. **落地写回**：找到第一个让条件为假的结果即写回原变量并继续；全部扰动都失败则打印
   「wrong: 无处可逃（没有合法结果）」并以退出码 1 终止。

```
fn main() {
    x = 10
    y = 20
    z = x + y
    wrong z == 30   // 条件为真 → 把根 x 随机加 1..5 → z 重算为 31..35
    print(x)        // 11..15（这次随机到几就是几）
    print(z)        // 31..35（与 x + y 保持相等）
}
```

## 持久性

与 `fate` 同构：`wrong` 的守卫在**编译期静态注册**。之后对该变量的任何赋值都会重新检查
条件，条件再次为真就再次驱逐。一条 `wrong` 能拦住后续每次"复现"：

```
fn main() {
    x = 10
    wrong x == 10
    x = 10          // 又归于 10 —— 守卫再次触发
    print(x)        // 11
}
```

三条链式 `wrong` 可以把 x 一路推走（10 → 11 → 12 → 13）。

## 编译期错误

| 写法 / 场景 | 报错 |
|---|---|
| `wrong 1 + 1 == 2`（条件不含变量） | 无可重算的参与值（条件不含任何变量） |
| `wrong arr[i] == 1` | 条件不能包含数组元素 |
| `wrong s == "hi"` | 条件只能由数值运算与比较组成 |
| 参与者未声明 | 参与者 '<名字>' 尚未声明 |
| 参与者类型未知 | 参与者 '<名字>' 类型未知 |
| 参与者是非数值类型 | 条件只能引用数值变量 |
| 参与者带后室/利息/一次性/双身状态 | 不支持对 '<名字>' 施加后室/利息/一次性/双身状态 |
| 参与值全是函数参数 | 参与值不能是函数参数 |

`lie` 遮蔽的场景：`wrong` 的条件被 `lie` 连值改写后变成常量 → 同样报"无可重算的参与值"。

## 边界 / 有意为之

- 派生链扩张上限 128 轮；出现环时环内变量降级为根（直接扰动）。
- 守卫函数 `__xfawa_wrong_<N>` 是模块级纯函数：闭包变量以指针传入，内部用影子存根模拟，
  成功后一次性写回真实变量。
- 注册是**静态**的：`wrong` 所在分支即使从不执行，也会登记监视（见"持久性"）；
  只有守卫**调用**本身是运行时门控。
- 实现位置：`src/llvm/xfawa_llvm_codegen.cpp`（`emitWrongGuard` / `codegen(WrongStatement)`，
  参与值解析 `wrongExprWalk`，生产者扫描 `collectWrongProducers`）；词法 / 语法 / AST / 语义层见
  `src/lexer/lexer.cpp`、`src/parser/parser.cpp`、`src/include/xfawa_ast.h`、
  `src/include/xfawa_semantic_analyzer.h`。
