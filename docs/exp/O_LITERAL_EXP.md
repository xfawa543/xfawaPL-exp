# o 十进制位字面量（o Decimal Literal）

一种用字母 `o` 写的实验性数字字面量（EXP）。

## 语法

```
o        → 10
oo       → 100
ooo      → 1000

1o       → 10
2o       → 20
15o      → 150
10o      → 100
```

## 规则

### 规则一：纯 o 序列

一串只由 `o` 组成的字面量，表示 `10` 的乘方：

| 写法 | 值 |
|------|-----|
| `o` | 10 |
| `oo` | 100 |
| `ooo` | 1000 |
| `oooo` | 10000 |

规律：`o` 表示 10，多写一个 `o` 就多乘一次 10，即 `n 个 o = 10^n`。

### 规则二：数字后面跟 o

先写数字，再接一个或多个 `o`，相当于数字前缀乘以 `10` 的 o 个数次方（即在数字后面补 0）：

| 写法 | 值 |
|------|-----|
| `1o` | 10 |
| `2o` | 20 |
| `12o` | 120 |
| `15o` | 150 |
| `123ooo` | 123000 |

规律：`数字前缀 × 10^o 的个数`。

### 混合加法（特殊）

当两个 o 字面量做加法时，两者的 `o` 个数会合并，而不是按普通数学相加：

```
1o + 1o = 100      （o 个数 1+1=2，数字前缀 1 → 1oo = 100）
```

这不是普通算术（普通算术 `1o + 1o` 应为 20），而是本 EXP 语法明确规定的特殊语义。

## 不可做的写法

```xf
oxygen = 10          // ✅ 合法：oxygen 只是普通 identifier，不是 o 字面量
int o = 20           // ✅ 合法：o 被当作变量名使用
oo = 5               // ✅ 合法：oo 是普通变量名
```

## 变量优先于字面量

如果你声明了一个名为 `o` 的变量，它的优先级高于 o 字面量：

```xf
int o = 42
print(o)   // 打印 42，不是 10
```

## 实现位置

- Lexer：普通 `o`/`oo` 序列保持为 `IDENTIFIER`（交由 parser 决定是否为字面量）；
  数字后紧跟 `o` 的形式（`1o`、`15o`、`10o`）在 `lexNumber()` 中产生 `O_LITERAL` token。
- Parser：把 `O_LITERAL` token 转成 `OLiteralExpression` AST 节点；
  对未被声明为变量的纯 `o` 标识符，也转成 `OLiteralExpression`。
- Codegen：计算 `OLiteralExpression` 的数值并生成对应 `i64`/`i32` 常量；
  `o 字面量 + o 字面量` 的特殊加法也在 codegen 中处理。
- 所有规则都集中在这条链上，不改 keyword 表、不改变现有 statement 语义。
