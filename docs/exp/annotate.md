# --annotate（编译器自动写注释）

让编译器**自己给代码写注释**。你只需要写代码，它会把你采用的 EXP 特性用注释标出来。

## 用法

在编译时加这个标志：

```
xfawac.exe 文件.xf --annotate
```

## 效果

给你一段代码：

```xf
boom
lie answer = 42 {
    print(answer)
}
```

运行 `--annotate` 之后，源代码被自动加上了注释（回复到源文件，UTF-8）：

```xf
// EXP: boom —— 让程序播放爆炸效果后正常退出
boom
// EXP: lie —— 修改变量的被观察值（真实值不变）
lie answer = 42 {
    print(answer)
}
```

贴补到了 AST 层面并且同样会被终端打印出来。

## 目前支持的语法

| 语法 | 说明 |
|---|---|
| `boom` | 让程序播放爆炸效果后正常退出 |
| `bsod` | 显示一个受控假蓝屏后继续执行 |
| `believe` | 让程序相信一个原本错误的事实 |
| `lie` | 修改变量的被观察值（真实值不变） |
| `un` | 禁用某个语言行为 |
| `ignore` | 忽略该语句，不执行 |
| `do` | 强制执行该语句，不受 un 影响 |
| `please.stmt` | 先打印 thank you! 再执行内部语句（不改 rage，也不算红温合规字） |
| 裸 `please` | 无运行时行为；仅红温（rage>=3）时 rage -1 并满足"每五行一次 please" |
| `shutup` | 立即压制后续所有 warning |
| `...` | 随机执行一个允许调用的安全动作 |

**注释对程序的行为没有任何影响**——它只是在你编译的时候加进原文件，并且不会运行（对运行结果零影响）。

## 边界

- 只影响最近的编译过程，写回源文件后保留。
- 如果多次运行 annotate 会重复添加；这个功能不支持重复聆还不存在的语法。
