# un

禁用某个语言关键字，让它临时"失效"。

## 语法

```xf
un print
un boom
un bsod
```

`un` 后面跟一个关键字：`print`、`boom`、`bsod`。

## 效果

```xf
un print

print("A")
!print("B")
print("C")
```

输出只有：

```
B
```

- 第一句 `print("A")` 不执行（被 `un print` 禁用了）
- 第二句 `!print("B")` 执行（`!` 强行绕过禁用）
- 第三句 `print("C")` 也不执行（没被豁免）

## 规则

- `!print` 只对**紧跟它的那一条** `print` 生效。
- `un` 支持的关闭对象：`print`、`boom`、`bsod`（其他语句暂不支持 `un`）。
- `un` 不想出产全世界，没有优先级或覆盖顺序的复杂性——目前是全局生效直到文件结束（不是块级范围）。

## 特殊用法提示

`!` 有一种用法：

```
un print     # 禁用 print
!print("x")  # 这一次强行打印
print("y")   # 还是不打印
```

注意 `!` 是旧的 `!print(...)` 写法，只能跟 `print`、`boom`、`bsod` 搭配，不能写 `!if` 或 `!int` 之类的。

## 注意事项

- 一旦 `un` 了，无法再取消——直到写回 `!` 标记的单次豁免。
- 目前 `un` 不受函数周期控制——意思是说你任何周期后之处，无法限定再禁止。
