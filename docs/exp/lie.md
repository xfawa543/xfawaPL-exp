# lie

让变量对外撒谎——变量本身的真实值不变，但在 `lie` 块内读到时，读到的是一个假值。

## 语法

```xf
lie 变量名 = 假值 {
    # 在这里面，读取这个变量得到的都是假值
}
```

## 效果

```xf
answer = 41

lie answer = 42 {
    print(answer)    # 打印 42
}

print(answer)        # 打印 41
```

变量 `answer` 的真实值一直是 `41`。但是在 `lie ... { ... }` 块里，`print(answer)` 打印出来的是 `42`。

## 规则

- `lie` 必须用 `{}` 包住受影响的代码。
- 谎言的作用域是**块级（block-scoped）**的：出了 `}` 谎言自动失效。
- 嵌套的 `lie`：内层覆盖外层谎言，离开内层后回到外层谎言。

```xf
x = 10

lie x = 99 {
    print(x)                # 99

    lie x = 77 {
        print(x)            # 77
    }

    print(x)                # 99
}

print(x)                    # 10
```

- 赋值会撕破谎言：如果在 `lie` 块里对这个变量赋值，谎言立即解除（读到真实值）。

```xf
x = 1

lie x = 99 {
    print(x)   # 99
    x = 5      # 重新赋值
    print(x)   # 5   <- 谎言结束了
}
```

## 注意事项

- 目前只支持**整数类型**的谎言值（数字）。字符串、浮点数的 `lie` 暂不支持。
- `lie` 不影响变量在内存/存储上的真实值，只影响读取。
