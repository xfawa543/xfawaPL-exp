# envy —— 嫉妒比自己更好的人

`envy a b` 让变量 `a`（嫉妒者）把变量 `b`（目标）当成可比较维度上的参照：如果 `b` 确实比 `a` **更好**，嫉妒机制就会立即处理这份"心理不平衡"。它**不是** `if a < b: a = b` 这种普通比较/赋值，也不只是"自己增强一点"——结果由**差距的悬殊程度**决定，可以是三件事之一：

> 「嫉妒一个比我好的人，所以我要**超越他**，**成为他**，或者**毁掉他的优势**。」

```
a = 50
b = 100
envy a b
print(a)   // 101 —— 超越（差距 = 自身，尚可一搏）
print(b)   // 100 —— 目标不变
```

```
poor = 10
rich = 100
envy poor rich
print(poor)  // 10  —— 自己不变
print(rich)  // 9   —— 销毁：目标被拉到穷人之下，失去优势
```

## 语法

```
envy <嫉妒者变量> <目标变量>
```

两个变量都必须是**已经存在的**（前面赋值过）；`envy` 不会自己创建变量。

## 触发条件

`envy` 首先判断"目标是否真的在某个可比较维度上优于自身"：

- `嫉妒者 >= 目标` —— 自身已经不弱于目标（包括平手）→ **不发生任何嫉妒行为**，两个变量原样不动。
- 只有 `内心者 < 目标` 时才进入三条路径之一。

## 三条嫉妒路径（确定性规则，一次嫉妒=一步）

设 `self = <嫉妒者>`、`target = <目标>`、`gap = target - self`（`gap > 0` 才会嫉妒）：

| 路径 | 心理 | 触发条件 | 结果 |
|---|---|---|---|
| 1. 超越 | 差距小，"努把力就能超过" | `gap <= self` | `self ← target + 1`，目标不变 |
| 2. 成为 | 差距中等，"我想变成他那样" | `self < gap <= 2×self` | `self ← target`（复制目标的数值），目标不变 |
| 3. 摧毁 | 差距悬殊，"我得不到，你也别想有" | `gap > 2×self`（绝望差距） | `target ← self - 1`（目标被拉到自身之下，失去优势），自己不变 |

路径选择完全由**当前状态**（当时的差距）决定，不是固定"自己加一点"：

```
c = 100      // 已经不弱 → 不动
d = 50
envy c d     // c=100, d=50

p = 40
q = 60       // gap=20 <= 40 → 超越
envy p q     // p=61, q=60

x = 30
y = 70       // 30 < gap=40 <= 60 → 成为
envy x y     // x=70, y=70
```

## 维度与类型

`envy` 只作用于**同一类型**的可比较维度：

- `int` vs `int`（同级）、`long` vs `long` —— 完整三条路径。
- `float` vs `float`（同级）—— 同样规则（浮点运算）。
- 其他任何组合 —— **不同数据类型下的不可比较维度**：
  - `bool`（布尔没有高低）、字符串、数组；
  - 整数宽度不同（int vs long）、整数 vs 浮点、浮点 vs 字符串……
  - 以及任一变量尚未声明。
  
  这些情况**不产生任何嫉妒行为**（原样保持），并输出一条 `[envy]` warning。

## 与 wrath / paradox / deja / fate 的关系

`envy` 是纯 codegen 运行的**逐次行为**（不修改历史或未来，不做 AST 变换），与 wrath（改历史）、paradox（幽灵下游）、deja（看未来）、fate（命运恢复）互不干涉；它只按当下的数值差距做事。

## 实现位置

- Lexer：`envy` → `KEYWORD_ENVY`。
- Parser：`envy <name> <name>` → `EnvyStatement`（记两个变量名；不声明变量）。
- AST：`NodeType::ENVY_STATEMENT`。
- Codegen（LLVM 直线 select，无分支）：`codegen(EnvyStatement*)` 查找双方 alloca，按上述规则构造 `gap → 路径 → 新值` 的 `icmp`/`fcmp` + `select` 链并回写原 alloca；类型不合/未声名则 `[envy]` warning + 返回占位值（避免中断语句生成）。

## 目前限制（已知）

- 只会比较"数值高低"这一个维度；没有字符串字典序、结构体等更复杂对象的比较与复制（"成为"对复杂对象并未实现状态复制，仅为数值复制）。
- 所有运算在当前整数宽度内进行，`target+1` / `self×2` 在极大值下可能溢出（文档规则已写死，测试用小数值）。
- `self <= 0` 时"超越/成为"的参照会失效（`gap > 2×self` 恒成立 → 一律走摧毁），这是"绝望差距"的有意边界，已在注释中记录。
